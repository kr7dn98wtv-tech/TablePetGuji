# 程序结构

- Model.cs：便携设置读写、穿搭目录、食物分类、拖动弹簧模型、散步与提醒调度。
- Art.cs：图集加载、透明像素命中、果冻变形、服装与道具绘制。
- PetWindow.cs：透明 WPF 桌面窗口、鼠标捕获、喂食、睡觉、动画与托盘。
- Shell.cs：衣橱、食物、杯具、设置、纸条、提醒卡和说话气泡。
- Program.cs：程序入口、单实例及现有自检。

设置位于程序旁 data/settings.xml，采用临时文件后替换写入，保留备份。图集加载后按部位裁切；衣服跟随身体网格变形，帽子和包包以独立部件定位。

提醒按用户本地作息运行，睡觉、专注或全屏时抑制，不堆积补发。散步机会低频触发。没有远程后端、账号系统或遥测。

开启开机启动会修改当前用户的 Windows Run 注册表项，可在设置中关闭。
