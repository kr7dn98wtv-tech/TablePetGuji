# 发布前的署名与来源检查

这是人工维护清单，不是已部署的监控或防盗系统。

- 作者署名使用“噜噜”，对外工作室署名使用“噜噜工作室”。
- 功能说明与实际版本一致，真实截图与AI概念图清楚区分。
- 检查README、版权和第三方声明是否与当前交付内容一致；发布包按确认后的方案保留相应说明。
- 公开仓库不自动加入付费配色、客户定制素材、未公开的订单或个人设置。
- 检查Git暂存文件，排除data、work、缓存、密钥、客户身份、聊天截图等资料。
- 新增素材与依赖需记录来源和适用条款；AI辅助生成保留原始输出、提示和人工修改过程。
- 发布时保存版本号、提交SHA、交付文件SHA256及发布地址。文件哈希不能单独证明作者身份或创作时间。
- 定制订单逐单明确交付内容、动作和衣服适配范围、使用范围、成品展示权限及是否独家。
- 正式买家授权、源码交付或独家权利转让，需要确认具体文本和实际权利主体，不把草案当成已生效合同。
- 发现疑似盗用时先保存链接、页面、时间及与本项目的对应关系，再由作者确认是否进行投诉或专业咨询；不自动对外发送指控。
