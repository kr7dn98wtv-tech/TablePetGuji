# 素材说明

形象与服饰、食物、道具采用 AI 辅助生成的透明 PNG 图集，配合程序切片、部件定位、透明像素命中与局部变形。

- body.png：绿色果冻身体。
- heads.png：基础头饰。
- clothes-front.png：早期单层衣服。
- wings-bags.png：翅膀与包包。
- props.png：杯具、小床、灯与其他道具。
- foods-v06.png：38种日常食物。
- wardrobe-v06.png：新增帽子；旧衣服图格保留在图集中，运行时已使用下一项替换。
- clothes-v07.png：按星夜冬眠版型调整的八件单层披衣。

不同图集保留了各次迭代的排版，部分图集使用自定义分行边界。修改后需同步检查 Art.Tile、头饰和衣服定位，以及衣橱预览，避免邻格碎片和遮挡嘴巴。

文档截图来自本程序实际绘制，不包含用户个人存档。
